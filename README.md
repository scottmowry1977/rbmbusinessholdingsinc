# RBM Business Holdings Inc. - Mobile & Web Application

This repository contains the official application for **RBM Business Holdings Inc.**, a professional consulting firm specializing in Financial, IT, and Business Strategy solutions.

## Overview

The application serves as a digital extension of the [rbmbusinessholdingsinc.com](https://rbmbusinessholdingsinc.com) website, providing a streamlined mobile and web experience for clients and partners.

### Key Features

- **Service Deep-Dives**: Detailed insights into our expertise in Financial Management, Managed IT Consulting, and Corporate Strategy.
- **Insights & News**: A professional blog feed providing the latest trends in tax strategy, IT modernization, and business growth.
- **Consultation Request System**: A built-in system for prospective clients to request professional consultations directly.
- **Unified Branding**: A professional UI featuring our signature Navy Blue and Gold Trim aesthetic.

## Tech Stack

- **Framework**: [Flutter](https://flutter.dev/) (Multi-platform support for Android, Web, and Windows).
- **Language**: Kotlin (Android) / Dart (Flutter logic).
- **Integration**: URL Launcher for seamless email and map connectivity.

## Project Structure

- `lib/`: Contains the core Dart code and UI screens.
- `android/`: Android-specific configuration and native code.
- `web/`: Web-specific configuration and hosting files.
- `windows/`: Windows-specific desktop configuration.

## Getting Started

### Prerequisites

- Flutter SDK (>= 3.0.0)
- Android Studio / VS Code
- Git

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/scottmowry1977/rbmbusinessholdingsinc.git
   ```
2. Navigate to the project directory:
   ```bash
   cd rbmbusinessholdingsinc
   ```
3. Get dependencies:
   ```bash
   flutter pub get
   ```
4. Run the application:
   ```bash
   flutter run
   ```
